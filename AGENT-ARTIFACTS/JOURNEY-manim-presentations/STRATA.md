**Rules for every stratum.**
- Per Minh: strata are larger than usual and have no blueprint. Each ends with looped FRESH Claude code reviews (HIGH/MEDIUM/LOW) until a round has only LOWs, then green CI. "End of … Period" strata get a whole-codebase review.
- One suite, `uv run pytest`, markers `unit, build, qt, export, e2e` (§3.11). Each stratum adds tests to it; every new test names its mutant, and the stratum's review mutation-tests them.
- Each stratum adds the `[tool.importlinter]` contracts (§3.1 arrows) for the modules it creates, in the same commit, and mutation-tests them. (Measured: lint-imports errors on a contract naming a module that does not exist yet, so contracts cannot be written ahead.)
- "CI green" includes CI wall time ≤ 30 min (§5 P5). Every stratum that adds `build`, `qt` or `export` tests (STRATUM 2 on) records and re-checks it; on a miss the §5 P5 remedy (session-scoped built edge fixture) is applied in that stratum; if still over after the remedy, report to Minh with the projection (the bound is his to change).
- A stratum that ships scaffolding names it and the stratum that deletes it.
- Host contention: every `uv run pytest` on mac-work-2 that selects `build`, `qt`, `export` or `e2e` tests, and every heavy probe or encode, holds `flock /tmp/mpres-heavy.lock` for its whole run (main stream and sub-journey alike), so no two heavy runs of ours overlap (in-run xdist overlap is accepted by §3.11; other agents' load is recorded beside any timing). Every reviewer prompt (main stream and sub-journey) states the host and this rule, because reviewers mutation-test. Local WebKit is killed by demonlock during LOCKED hours (DECISIONS); CI is authoritative for WebKit.
