# manim-presentations

[![CI](https://github.com/MT-GoCode/manim-presentations-UI-and-harness/actions/workflows/ci.yml/badge.svg)](https://github.com/MT-GoCode/manim-presentations-UI-and-harness/actions/workflows/ci.yml)

Give talks made of Manim animations, with a private **Presenter View** (notes, script, big Previous / Next / Replay
buttons) and a separate **Audience View** window to screen-share. Builds are incremental, parallel and verified.

The first `./setup.sh` takes several minutes (it downloads TeX); run it detached or with a long timeout.

```
git clone https://github.com/MT-GoCode/manim-presentations-UI-and-harness
cd manim-presentations-UI-and-harness && ./setup.sh
```

macOS only. MIT licensed.
